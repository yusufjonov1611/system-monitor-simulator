🔍 Nima Uchun Monitoring Ko'rsatkichlari Operatsion Tizimga Bog'liq?

Dars davomida o'quvchilarga tushuntirilishi kerak bo'lgan eng muhim arxitekturaviy farqlar:

CPU Monitoring

Load Average vs CPU %

🐧 Linux / Unix:

Load Average (1, 5, 15 daqiqa) ko'rsatkichini ishlatadi. Bu protsessor bajarishini kutayotgan yoki disk kutayotgan jarayonlar navbati uzunligidir. 4 yadroli kompyuterda Load Average = 4.0 bo'lsa, tizim 100% to'la!

🪟 Windows:

Load Average tushunchasi mavjud emas. Windows faqat % Processor Time (har bir yadro foizi) va kamdan-kam Processor Queue Length orqali o'lchaydi.

Xotira Boshqaruvi

"Free RAM" vs "Cached RAM"

🐧 Linux falsafasi:

"Bo'sh turgan RAM - isrof qilingan RAMdir!" Linux bo'sh xotirani avtomatik ravishda disk keshiga (Page Cache / Buffers) aylantiradi. Dasturga xotira kerak bo'lsa, kesh bir zumda bo'shatiladi.

🪟 Windows yondashuvi:

Windows xotirani In Use, Modified, Standby (kesh) va Free ro'yxatlariga bo'ladi. Task Manager foydalanuvchiga faqat amaliy ishlatilayotgan xotira foizini ko'rsatadi.

Virtual Xotira

Swap Partition vs Pagefile.sys

🐧 Linux:

Odatda alohida Swap bo'limi (Partition) yoki /swapfile ishlatiladi. Xotira to'liq to'lganda mashhur OOM Killer (Out Of Memory Killer) algoritmi ishga tushib, eng katta jarayonni majburiy to'xtatadi.

🪟 Windows:

Diskda yashirin pagefile.sys fayli shaklida bo'ladi. Xotira tugasa, Windows ogohlantirish chiqaradi va dasturlar sekinlashib "Not Responding" holatiga tushadi.

Disk Tizimi

Disk Harflari (C:, D:) vs VFS Ierarxiyasi (/)

🐧 Linux VFS:

Harflar umuman yo'q. Hamma narsa yagona ildiz / (root) katalogiga ulangan. Har bir disk yoki fleshka /mnt yoki /media ichiga ulanadi (mount qilinadi).

🪟 Windows Drive Letters:

Har bir disk bo'limi alohida harf bilan belgilanadi: C:\ (tizim), D:\ (ma'lumotlar), E:\ (fleshka). Fayl yo'llari teskari slesh (\) bilan yoziladi.

📖 Dars Konspekti: Kompyuter Holatini Monitoring Qilish

1. Monitoring nima va nega u zarur?

Monitoring — bu operatsion tizim va apparat resurslarining (CPU, RAM, Disk, Tarmoq) joriy parametrlarini uzluksiz kuzatish, qayd etish va tahlil qilish jarayonidir. Monitoring orqali:

  • Dasturlar muzlab qolishi (hang) sabablari aniqlanadi.
  • Tizim qizib ketishi (termal trottling) oldi olinadi.
  • Kiberhujumlar (DDoS, viruslar, mining dasturlari) o'z vaqtida fosh qilinadi.
  • Server va bulutli tizimlarning uzluksiz ishlashi (99.9% uptime) ta'minlanadi.

2. Python tilida monitoring qanday amalga oshiriladi?

Python tilida tizim ko'rsatkichlarini olish uchun eng ommabop va kuchli kutubxona — psutil (process and system utilities) hisoblanadi:

import psutil

# 1. CPU foizi
cpu = psutil.cpu_percent(interval=1)

# 2. Xotira (RAM)
ram = psutil.virtual_memory()
print(f"Ishlatilayotgan RAM: {ram.percent}%")

# 3. Disk bandligi
disk = psutil.disk_usage('/')
print(f"Bo'sh joy: {disk.free / (1024**3):.1f} GB")

3. Darsda o'quvchilarga beriladigan amaliy topshiriqlar

  1. 1-topshiriq: Simulyator panelida "CPU 100% Stress" ssenariysini yoqing va uning haroratga ta'sirini kuzating. Trottling nima ekanligini tushuntiring.
  2. 2-topshiriq: "Bir Yadro vs Ko'p Yadro" rejimini yoqib, nega bitta yadroli dasturlash zamonaviy 8 yadroli protsessor quvvatini to'liq ishlata olmasligini tahlil qiling.
  3. 3-topshiriq: Linux va Windows tizimlarida xotira boshqaruvi (Swap vs Pagefile) farqini jadval orqali daftarga qayd eting.
